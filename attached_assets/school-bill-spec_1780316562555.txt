<h2>1. Overview &amp; Purpose</h2>
<p>A <strong>frontend-only</strong> React + TypeScript web application that lets school administrators generate, configure, and print term fee bills for students. No backend, no database — everything is stored in <code>localStorage</code>. Bills are formatted for <strong>A4 print, 2 bills per page</strong> with a dashed cut-line between them.</p>

<div class="card">
  <h4>Core capabilities</h4>
  <ul>
    <li>Generate individual student bills with auto-calculated fees</li>
    <li>Generate a 2-bill-per-A4-sheet print layout</li>
    <li>Configure all fee items (label, amount, period, term), add/delete items</li>
    <li>Configure feeding fees per class level per term</li>
    <li>Configure transport zones with fees per level</li>
    <li>School info, logo, bank payment details all editable</li>
    <li>Bill appearance: logo size, watermark (text or image), background repeating-text pattern</li>
    <li>Setup wizard for first-time use; admin wizard for full blank-slate setup</li>
    <li>Export settings as JSON; import settings from JSON</li>
    <li>Reset to defaults or wipe all data</li>
    <li>All changes auto-saved to localStorage on every update</li>
  </ul>
</div>

<h2>4. Data Model (TypeScript types)</h2>

<pre><code>// localStorage key
const STORAGE_KEY = 'saSchoolBillSettings';

interface FeeItem {
  id: string;         // unique string, e.g. 'tuition', 'item_1234567890'
  label: string;      // displayed on bill, e.g. 'Tuition Fee'
  amount: number;     // GH¢ amount
  period: string;     // displayed in Period column, e.g. 'Per Term', 'Per Year', ''
  terms: 'all' | '1' | '2' | '3'; // which term(s) this item appears in
}

interface LevelFees {
  label: string;               // e.g. 'Lower Primary'
  classes: string[];           // class names for this level, e.g. ['Lower Primary']
  hasArrears: boolean;         // show arrears row on bill?
  items: FeeItem[];            // fee line items
  feeding: { '1': number; '2': number; '3': number }; // feeding fee per term
}

interface TransportZone {
  id: string;    // 'ssnit', 'elmina', 'ankaful', 'quarters', 'ataabadze', 'none'
  label: string; // display name
  fees: { creche: number; nursery: number; kg: number; lp: number; up: number; jhs: number };
}

interface SchoolInfo {
  name: string;        // e.g. 'St. Anne Catholic School'
  subtitle: string;    // e.g. 'Nkontrodo, Elmina'
  address: string;     // e.g. 'P.O. Box 58, Elmina, Central Region'
  logo: string | null; // base64 data URL or null
}

interface AcademicInfo {
  year: string;           // e.g. '2025-2026'
  term: '1' | '2' | '3'; // current term
  reopening: string;      // e.g. 'Monday, 7th September 2026'
}

interface BankInfo {
  name: string;        // e.g. 'GCB Bank Ltd'
  branch: string;      // e.g. 'Elmina Branch'
  account: string;     // account number
  accountName: string; // account holder name
}

interface WatermarkSettings {
  enabled: boolean;
  mode: 'text' | 'image';
  text: string;          // e.g. 'OFFICIAL'
  image: string | null;  // base64 data URL
  opacity: number;       // 0-100 (shown as %, default 15)
  rotation: number;      // degrees, default -35
  size: number;          // % scale, default 100
}

interface BackgroundTextSettings {
  enabled: boolean;
  text: string;       // custom text; blank = use school name
  fontSize: number;   // 5-20, default 8
  opacity: number;    // 1-30 (as %, default 6)
  color: string;      // hex, default '#1B2D5B'
  spacing: number;    // 40-300, default 120 (SVG pattern tile width px)
  rotation: number;   // -90 to 90, default -30
}

interface Settings {
  school: SchoolInfo;
  academic: AcademicInfo;
  bank: BankInfo;
  fees: {
    creche: LevelFees;
    nursery: LevelFees;
    kg: LevelFees;
    lp: LevelFees;
    up: LevelFees;
    jhs: LevelFees;
  };
  transport: TransportZone[];
  logoSize?: number;               // 10-200, default 100 (%)
  watermark?: WatermarkSettings;
  background?: BackgroundTextSettings;
  _blank?: boolean;                // true = all amounts are 0 (admin blank state)
}

type LevelKey = 'creche' | 'nursery' | 'kg' | 'lp' | 'up' | 'jhs';

// Calculated bill (output of calcBill())
interface BillResult {
  name: string;
  className: string;
  classHeaderLabel: string;   // always 'Class:'
  classHeaderDisplay: string; // same as className
  term: string;
  lv: LevelKey;
  trId: string;               // transport zone id
  items: { label: string; amount: number; period: string }[];
  baseTotal: number;
  varItems: { label: string; amount: number; period: string; zone?: string }[];
  varTotal: number;
  grandTotal: number;
  arrears: number | null;
  hasArrears: boolean;
}</code></pre>

<h2>7. Bill Calculation Logic (<code>calcBill</code>)</h2>

<pre><code>function calcBill(bdata: BillData, S: Settings): BillResult | null {
  const { level, term, transport, arrears } = bdata;
  const lvFees = S.fees[level];  // get the level's fee config

  // 1. Fixed fee items — filter by term
  //    Include item if: item.terms === 'all' OR item.terms === currentTerm
  const items = lvFees.items.filter(it => it.terms === 'all' || it.terms === term);

  // 2. baseTotal = sum of filtered items

  // 3. Variable items (feeding + optional transport)
  //    Feeding: lvFees.feeding[term]
  //    Transport: only if trId !== 'none'
  //      amount = trZone.fees[level]
  //      period label = zoneName + " Per Term"

  // 4. varTotal = feeding + transport
  // 5. grandTotal = baseTotal + varTotal

  // 6. Arrears — only if lvFees.hasArrears === true
  //    value = parseFloat(bdata.arrears) || 0

  // classHeaderLabel is always 'Class:'
  // classHeaderDisplay is the className string

  return { name, className, classHeaderLabel: 'Class:', term, lv, trId,
           items, baseTotal, varItems, varTotal, grandTotal,
           arrears (null if !hasArrears), hasArrears };
}</code></pre>

<h2>16. Important Behaviours &amp; Edge Cases</h2>

<ul>
  <li><strong>Auto-save</strong>: Every call to <code>updateS()</code> triggers <code>localStorage.setItem</code> synchronously. There is no debounce.</li>
  <li><strong>Term filtering</strong>: Fee items with <code>terms='all'</code> always appear. Items with <code>terms='1'|'2'|'3'</code> only appear in that specific term. Feeding uses a separate per-term lookup.</li>
  <li><strong>Transport on bill</strong>: If <code>trId === 'none'</code>, no transport fee row is added to the bill and no transport line is shown in the header area. The "No Transport" label never appears on the bill itself.</li>
  <li><strong>Arrears</strong>: Only shown for levels where <code>hasArrears=true</code> (lp, up, jhs). If the arrears amount is 0, the row still renders but the value cell is blank (showing "_ _ _" dotted lines for handwriting).</li>
  <li><strong>Logo initials fallback</strong>: If no logo uploaded, shows a navy circle with the initials (first letter of each word in school name, max 2 chars, uppercase).</li>
  <li><strong>Background SVG pattern</strong>: Uses inline SVG <code>&lt;pattern&gt;</code> with <code>&lt;text&gt;</code> child. Pattern ID must be unique per bill on the same page (use billId prop: <code>bgp-{billId}</code>) to avoid one bill's pattern bleeding into another on the A4 sheet.</li>
  <li><strong>Watermark z-index</strong>: Both background pattern and watermark sit at <code>zIndex: 0</code>. All bill content sits in a <code>zIndex: 1</code> wrapper so it renders above the overlays.</li>
  <li><strong>Print font sizes</strong>: Entire bill uses pt units when <code>isPrint=true</code>, px units when <code>isPrint=false</code>. This is critical for correct A4 sizing.</li>
  <li><strong>Import merge strategy</strong>: Imported JSON is deep-merged on top of DEFS (not directly applied), so any missing keys default to DEFS values. Then <code>applyDefaults</code> and <code>migrateClasses</code> run.</li>
  <li><strong>Wizard trigger</strong>: On mount, if <code>localStorage</code> has no data → show SetupWizard after 500ms. If data exists but <code>_blank===true</code> → show AdminSetupWizard after 500ms.</li>
  <li><strong>Fee table key</strong>: The fee items table uses <code>key={activeLv}</code> to force a full remount when switching level tabs, so controlled inputs reset to the new level's values.</li>
</ul>

────────────────────────────────────────
BILL CALCULATION (calcBill function)
────────────────────────────────────────
1. Filter lvFees.items by: terms==='all' OR terms===currentTerm
2. baseTotal = sum of filtered items
3. varItems: always add Feeding (lvFees.feeding[term])
4. If transport trId !== 'none': add Transport (trZone.fees[level], label = zoneName + " Per Term")
5. varTotal = sum varItems, grandTotal = baseTotal + varTotal
6. Arrears: include if hasArrears (null otherwise)
7. classHeaderLabel = 'Class:'

────────────────────────────────────────
BILL DOCUMENT STRUCTURE (BillRenderer)
────────────────────────────────────────
position:relative wrapper. Two absolute overlays (z:0): SVG background pattern and/or watermark. Content wrapper at z:1.

LETTERHEAD (3-col grid):
  Left: school name (Playfair Display, uppercase, #1B2D5B) + subtitle + address
  Center: logo img OR initials circle
  Right: "Payment Details" heading + bank info
  Separated from body by 2px solid #1B2D5B border-bottom

NAME ROW: "NAME" bold + underline fill line + "Class:" + className value (Crimson Pro)

TRANSPORT LINE: italic, small — "Transport: [zone]" — HIDDEN when trId==='none'

TITLE: centered italic "Child's Bill" (Playfair Display)

FEE TABLE (4 cols: Description | GH¢ | Amount | Period):
  All fixed fee items → spacer row → TOTAL (bold, #f8f8f6 bg) → Feeding row → Transport row (if any) → TOTAL (grand total) → ARREARS row (if hasArrears)
  ARREARS: shows value if >0, else blank dotted lines for handwriting

FOOTER: "School Reopens: [date]" centered italic (only if reopening set)
